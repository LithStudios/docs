# Lith Studios - FiveM Scripts

This collection includes professionally developed scripts spanning various categories:

* **Crime & Heist Systems** - Pickpocketing, snatch & grab, locker theft, cartel heist
* **Job Systems** - Cleaning, lawn mowing
* **Vehicle Systems** - Wheel spacers, handbrake, brake cutting
* **Utility & Admin Tools** - Image placer, 3D signs, props viewer, bolt minigame

## Included Scripts

### Crime & Heist Scripts

* [Pickpocketing](premium-scripts/pickpocketing/) - NPC pickpocketing with difficulty-based minigames
* [Snatch & Grab](premium-scripts/snatch-and-grab/) - Street robbery system with police dispatch
* [Locker Theft](premium-scripts/postal-locker-theft/) - Post office locker robbery mechanics
* [Cartel Heist](premium-scripts/cartel-heist/) - Complete island heist mission with NPCs

### Job Scripts

* [Cleaning Job](premium-scripts/apartment-cleaning/) - Apartment cleaning with theft opportunities
* [Mower Job](premium-scripts/mower-job/) - Lawn mowing job with progression system

### Vehicle Scripts

* [Wheel Spacers](premium-scripts/wheelspacers/) - Advanced wheel modification system
* [Manual Handbrake](premium-scripts/manual-handbrake/) - Realistic handbrake physics
* [Brake Cutting](premium-scripts/brake-cutting/) - Vehicle sabotage mechanics

### Utility Scripts

* [Bolt Minigame](free-scripts/bolt-minigame/) - Interactive bolt tightening minigame
* [Image Placer](premium-scripts/real-time-image-placer/) - Developer tool for placing images in-game
* [Real-Time 3D Signs](premium-scripts/signs/) - Place persistent 3D text signs with Lith font packs
* [Props Viewer](premium-scripts/viewable-props/) - Display images on props/objects

## Framework Support

Most scripts support multiple frameworks:

* **ESX** - Full support with adapters
* **QBCore** - Full support with adapters
* **QBox** - Full support with adapters
* **Standalone** - Some scripts work without framework

## Common Features

All Lith Studios scripts include:

* Clean, optimized code
* Comprehensive configuration options
* Multi-language locale support
* Debug modes for troubleshooting
* Professional documentation
* Regular updates and support
