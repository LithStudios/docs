# Wheelspacers

## Features

* Interactive wheel spacer installation and removal
* Real-time visual wheel offset modifications
* Customizable spacing values and presets
* Installation/removal minigame system

## Installation

{% stepper %}
{% step %}
### Place resource

Place `ls_wheelspacers` in your resources folder.
{% endstep %}

{% step %}
### Configure

Configure the script (see Configuration section).
{% endstep %}

{% step %}
### Add to server.cfg

```cfg
ensure ls_wheelspacers
```
{% endstep %}

{% step %}
### Restart

Restart your server.
{% endstep %}
{% endstepper %}

## Dependencies

* Required:
  * None (standalone)
* Recommended:
  * Framework (ESX/QBCore) for job data
  * Vehicle system for modification persistence
  * Banking system for payments
