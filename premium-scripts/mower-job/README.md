# Mower job

## Features

* Interactive lawn mowing with vehicle control mechanics
* Multiple property assignments with varying sizes

## Installation

1. Place `ls_mower` in your resources folder
2. Configure the script (see Configuration section)
3. Add to server.cfg:

```cfg
ensure ls_mower
```

4. Restart your server

## Dependencies

* **Required:**
  * None (standalone)
* **Recommended:**
  * Framework (ESX/QBCore) for job management
